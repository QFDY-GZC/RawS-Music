# RawSMusic 1.0.13-release

更新时间：2026 年 10 月 13 日


## 新增

- 新增 COUI 风格进度条效果。
- 新增播放界面屏幕常亮设置。
- 新增超级岛封面显示及封面取色效果。
- 新增 SACD-ISO 镜像读取，自动解析并识别镜像内的 DSD 曲目；格式转换同时支持 SACD-ISO 输出。
- 新增混响音效，支持空间场景预设与参数调节。

## 优化

- 为 Android API 32 及以上设备完善圆角适配。
- 播放界面切歌时，标题、歌词等变化内容支持 UI 淡入淡出过渡。
- 优化自动交叉淡入淡出的触发、混音与交接逻辑。
- 优化歌词语言显示。

## 修复

- 修复车载歌词传递的部分问题。
- 修复注音中的空格处理问题。
- 修复超级岛歌词显示异常。
- 修复冷启动后背景取色不同步的问题。
- 修复部分情况下混音导致音调加速、异常二次切歌的问题。
- 修复 USB 独占下歌曲临近结束时突然暂停，以及再次点击播放时重新播放音频的问题。
- 修复 USB 独占下因音量比较异常导致上一首播放失败的问题。
- 修复格式转换成功后仍提示内部转换失败的问题。
- 修复 FLAC 转 FLAC 时容器校验失败的问题。
- 修复注音预留空间不足导致位置不一致的问题。
- 修复展开播放界面时出现短暂黑屏的问题。
- 修复部分情况下 USB 重启或卡死的问题。
- 修复歌词源名称显示异常，不再显示未解析的资源名称。
- 修复批量匹配大量歌词时的内存瓶颈。
