# 功能、格式与兼容性

[返回介绍](../README.md) · [English](../README_EN.md) · [日本語](../README_JA.md) · [한국어](../README_KO.md)

本页描述当前实现的功能范围；设备、文件特征、权限和输出模式会影响可用项。界面里显示一个选项，不意味着所有设备都能使用该能力。

## 曲库与播放

- 本地扫描、所选文件夹访问与文件夹层级；歌曲、专辑、艺术家、作曲家、流派、年份、最近添加、播放列表及播放统计。
- 多种排序、紧凑/标准/大封面列表及网格布局；曲库搜索与播放队列管理。
- 无缝播放，手动短时交叉渐隐，自动交叉淡入淡出。智能交接结合歌词与能量分析，调整旧轨退出、新轨进入及界面更新时间；可临时取消当前片段。
- AudioTrack、AAudio、OpenSL ES、Direct / Hi-Res 输出路径。实际采样率与位深以当前设备及播放链路为准。
- USB DAC 独占输出在发行 APK 中提供；PCM、DoP、Native DSD、硬件/软件音量及高采样率均需要设备支持。完整 USB 核心当前不在公开仓库内。

## 歌词

逐行、逐字歌词可以配合翻译、罗马音和日语注音显示。日语歌词使用语言信息选择合适的汉字字形，注音按正文片段定位，长行按布局宽度换行。切句与跨句移动使用弹簧过渡，并提供手势缩放及字体/间距设置。

支持内嵌歌词读取、歌词搜索及应用预览、批量匹配和 Lyrico 插件。歌词源、网络状态与歌曲信息会影响匹配结果；插件可执行代码并使用其获准的主机接口，请选择可信来源。

超级岛歌词、封面与颜色，以及 Lyricon 桥接和车载信息传递，依赖 ROM、系统权限与接收端。部分系统路径需要 Shizuku；这是适配功能，不能据此宣称所有 Android 或所有车机均支持。

## 音效

均衡器、空间与动态处理、混响、ReplayGain、DVC、重采样和速度/音调控制可按场景调节。混响提供多个场景、空间类型及自定义参数保存。参数可能相互影响，严格 bit-perfect 或原生 DSD 路径会限制可用处理。

## 格式转换

转换目标由 `AudioTranscodeFormat` 声明，并在运行时核对编码能力：

| 类型 | 目标 |
| :-- | :-- |
| 无损 / PCM | FLAC、Ogg FLAC、WAV、AIFF、ALAC、WavPack、TTA |
| DSD | DSF、SACD-ISO |
| 有损 | AAC（M4A）、MP2、MP3、Opus、Vorbis、WMA |

批量队列支持单曲参数、取消、结果管理及元数据迁移。不同目标格式对标签、封面与歌词的承载能力不同；应用保留的额外元数据不一定被其他播放器识别。

SACD-ISO 的生成目标目前为 **DSD64 双声道**，用于应用内转换与测试，不等于实体 SACD 光盘制作或所有 SACD 制作规格的完整实现。读取支持 SACD 曲目解析与 DSD / DST 路径，但最终兼容性仍需要真实镜像验证。PCM 转 DSD、提高采样率或位深不会凭空增加原始录音的信息。

## 外观与扩展工具

Miuix 界面、亮暗主题、封面取色、流光背景、液态玻璃、图片或视频背景、字体和歌词布局、播放页面常亮可分别设置。图片中的自定义字体和主题并非唯一默认外观。

WebDAV 用于网络音乐访问；分析、歌词视频以及可选 AI 工具各有资源需求。模型、插件或网络歌词可能需要联网获取，本地已有文件的播放与读取不应被描述为所有扩展功能均离线可用。
